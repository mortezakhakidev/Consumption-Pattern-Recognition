# Consumption Pattern Recognition
Optimal Scheduling and Pattern Recognition of Appliance Usage Using the Apriori Algorithm

## Project Overview

This project leverages the **Apriori algorithm** to optimize the scheduling and allocation of household appliances based on electricity consumption patterns.

By analyzing historical appliance usage data, the algorithm identifies frequent combinations of devices that are commonly used together. These patterns are then used to allocate power and operating time within predefined limits, ensuring efficient energy usage while avoiding excessive consumption.

The system considers two main constraints:
- The total power consumption of appliances should not exceed the user's predefined power limit.
- The allocated operating time for each appliance should satisfy minimum usage requirements.

The goal of this project is to discover energy-efficient usage patterns that match user behavior, reduce unnecessary energy waste, and improve household appliance scheduling.
